# Gestión de Datos - Arrays, Sets y Maps

Este script (`gestion_datos.js`) es un ejercicio práctico diseñado para consolidar el entendimiento y la aplicación de estructuras de datos avanzadas en JavaScript.

## 🎯 Objetivos del Script
1. **Manipulación de Objetos**: Creación de un arreglo que almacena múltiples productos con sus propiedades (`id`, `nombre`, `precio`).
2. **Uso de Sets**: Demostración de cómo la estructura `Set` garantiza la unicidad de los datos, filtrando automáticamente valores numéricos repetidos. Implementación de sus métodos `.add()`, `.has()` y `.delete()`.
3. **Uso de Maps**: Uso de `Map` para crear diccionarios de datos o arreglos asociativos que relacionan una clave (categoría) con un valor (producto).
4. **Bucles de Iteración Avanzada**:
   - `for...of`: Para recorrer arreglos y Sets.
   - `for...in`: Específico para recorrer las propiedades (claves) de un objeto.
   - `.forEach()`: Método moderno para recorrer la estructura del Map.
5. **Validación Lógica**: Uso de condicionales `if/else` para asegurar la integridad de los datos de un producto (verificación de campos vacíos o numéricos).

## 🚀 Cómo ejecutarlo
Este es un script puro de JavaScript. Para ver los resultados y la salida en consola, puedes:
1. Instalar Node.js en tu sistema.
2. Ejecutar el siguiente comando en la terminal desde esta carpeta:
   ```bash
   node gestion_datos.js
   ```
*(Alternativamente, puedes enlazar este archivo a un HTML vacío mediante la etiqueta `<script>` y verlo en la consola del navegador).*
